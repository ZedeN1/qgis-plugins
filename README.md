# QGIS Plugins

Custom QGIS plugin repository. Add it to QGIS to install and receive updates
for all plugins listed below.

## Add to QGIS

1. Open **Plugins → Manage and Install Plugins → Settings**
2. Under *Plugin Repositories*, click **Add**
3. Enter any name and the following URL:

https://ZedeN1.github.io/qgis-plugins/plugins.xml
